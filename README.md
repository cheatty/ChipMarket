# ChipMarket Android

Проект для Android Studio на Kotlin и Jetpack Compose. Откройте папку `ChipMarketAndroid`, дождитесь Gradle Sync и запустите конфигурацию `app`.

## Структура

- `data/model` — модели товара, заказа, профиля и сессии.
- `data/remote` — HTTP-клиент Supabase.
- `data/repository` — каталог, авторизация, корзина, избранное, профиль, заказы и публикация товаров.
- `navigation` — список экранов.
- `presentation` — состояние приложения и действия пользователя.
- `ui/components` — общие карточки, нижняя навигация и карта 2ГИС.
- `ui/screens` — отдельный файл для каждого экрана.
- `ui/theme` — цвета, форматирование цен и дата доставки.

## Supabase

Адрес проекта и публичный ключ находятся в `supabase.properties`. Gradle переносит их в `BuildConfig.SUPABASE_URL` и `BuildConfig.SUPABASE_PUBLISHABLE_KEY` в `app/build.gradle.kts`.

Подключение выполняется в `data/remote/SupabaseClient.kt`. Запросы каталога, Auth, Storage, корзины, избранного, профиля и заказов находятся в `data/repository/StoreRepository.kt`.

Изображения макета находятся в публичном бакете `chipmarket-assets`. Ссылки изображений товаров хранятся в `public.products.image_url` и `public.products.image_urls`. Подготовленные записи с публичными URL изображений находятся в `supabase/catalog_seed.json`, а запрос для безопасного добавления без дублей — в `supabase/catalog_seed.sql`.

## Карта 2ГИС

Экран оформления заказа использует интерактивную карту 2ГИС MapGL. Карта собирается из тайлов 2ГИС, есть кнопки масштаба и полноэкранный режим. Без ключа остаётся изображение-заглушка.

1. В кабинете 2ГИС подключите `Map Tiles API` или `MapGL JS API` и создайте ключ.
2. Откройте локальный файл `local.properties` в корне проекта.
3. Добавьте строку `DGIS_MAPGL_KEY=ваш_ключ`.
4. Выполните Gradle Sync и снова запустите приложение.

Ключ передаётся через `BuildConfig.DGIS_MAPGL_KEY`, а карта пункта выдачи находится в `ui/components/PickupPointMap.kt`. Координаты пункта выдачи заданы константами `PICKUP_LAT` и `PICKUP_LON`.

## Каталог

Карточки показывают название, описание, цену, старую цену и изображение. На странице товара доступны галерея, полное описание, характеристики, остаток и похожие товары из той же категории. Категории формируются автоматически из данных Supabase.

Работник может выбрать до пяти фотографий. Приложение сжимает их, загружает в Supabase Storage и публикует товар через `chipmarket_publish_product`.

## Покупатели и продавцы

Схема магазина находится в `supabase/marketplace_accounts.sql`. Она добавляет username и название магазина продавца, публичный справочник магазинов и закрытое представление `chipmarket_order_audit`.

В `chipmarket_order_audit` владелец базы видит заказ, ник и почту покупателя, товар, количество, сумму и магазин продавца. Обычным пользователям это представление недоступно.

Продавец регистрируется через кнопку «Стать продавцом», указывает username и название магазина, а опубликованные товары появляются в общем каталоге с подписью магазина.
